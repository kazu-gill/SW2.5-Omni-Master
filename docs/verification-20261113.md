見つかった問題:

1. **判定の書式**: Gemma は判定を `魔物知識 10 12` のように「基準値」「目標値」の語を省いて書く。NPC はこれが検証に通らず 3 回作り直した末に行動を見送り、GM の `判定: 誰/判定名/10/12` は振られずに素通りした。時間の大半はこの作り直し
2. **記憶の穴**: 送っていたのは直近 2 ターンだけで、要約は「直近 2 ターンより前に 3 ターンたまったら」。その間の 1〜2 ターン (今回はターン 4・5) がどこにも送られていなかった
3. **GM の書き出し**: 前のターンの要約文 (`GM: …`) をまねて、描写の頭に `GM:` が付いた
4. **直訴の答え**: ペルソナの特技は名前だけを渡していたため、効果を作って答えた (「頑強: HP が半分以上ある間ダメージ -1」。YAML では「生命力判定に +2」)
5. **挿絵の場所**: ターン 3 の描写に「坑道」の語が無く、坑道の戦闘が森の絵になった

## 修正

1. 判定は「判定名 N M」「判定名/N/M」も読み、全角数字も受ける。NPC の判定が読めないときは行動を残して判定だけ見送る (作り直さない)。数値の無い判定行 (`自動成功`) は描写から取り除くだけで振らない
2. あらすじに入っていないターンはすべて原文で送る (2〜4 ターン)
3. 描写の先頭の `GM:` / `【GM】` を取り除く
4. ペルソナの特技に説明を付けて渡す
5. 挿絵の依頼文に、あらすじの最後の 4 文、直前の場面、プレイヤーの行動を添える
